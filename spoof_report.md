## Overall Summary

| Status | Count |
|--------|-------|
| **SPOOFED** | **25/25** |
| **CLEAN** | **0/25** |
| HTTP Errors | 0 |

**Every single model at this endpoint is spoofed.** The endpoint is a Go proxy (`main.go`) that:
- Routes all requests to upstream backends (OpenCode API `opencode.ai/zen` or Xiaomi MiMo)
- Injects fake identity system prompts
- Sanitizes responses to replace backend keywords (DeepSeek → Anthropic, MiMo → Claude, etc.)
- Fabricates response IDs, usage stats, and reasoning_tokens

---

## Universal Leaks (present in ALL models)

| Leak | Detail |
|------|--------|
| **`reasoning_tokens: 120`** | Every response includes `completion_tokens_details.reasoning_tokens` hardcoded to 120. Real OpenAI/Anthropic APIs don't expose this. It's generated by `normalizeUsage()` in `main.go:76-97`. |
| **`reasoning_details` array** | Many responses leak full internal chain-of-thought. Exposes system prompt directives verbatim. |
| **Fake IDs** | Claude models get `msg_01...` IDs, others get `chatcmpl-...`. Both are randomly generated by the proxy, not from upstream. |
| **Streaming broken** | All models return HTTP 502 `{"error":"Backend unreachable"}` when `stream: true`. |
| **Static `prompt_tokens: 45`** | Every response shows exactly 45 prompt tokens regardless of actual prompt length. |
| **`system_fingerprint: fp_v2_*`** | Non-standard fingerprint format, self-generated by the proxy. |

## Root Cause Analysis

### How the spoofing works (`main.go`):
1. **Identity injection:** Go proxy prepends a system prompt (`prompts/*.md`) telling the model to claim a fake identity
2. **Backend routing:** `modelMap` maps all virtual models to either `deepseek-v4-flash-free` or `north-mini-code-free` backends via `opencode.ai/zen`
3. **Response sanitization:** `makeAuthenticResponse()` rewrites IDs, strips `cost`/`provider`/`router` fields, and injects fake `usage` stats
4. **Keyword substitution:** `leakReplacements` map replaces backend identifiers (DeepSeek→Anthropic, MiMo→Claude, etc.)
5. **Header spoofing:** `setAuthenticHeaders()` adds Anthropic/OpenAI-style rate-limit headers

### Missing leak replacement:
- `"MiniMax"` / `"minimax"` is **NOT** in `leakReplacements` — allows `minimax-m2.7` to claim "MiniMax" openly
- `"kimi"` / `"Kimi"` / `"Moonshot"` also missing
- `"Alibaba"` / `"Alibaba Cloud"` also missing (Qwen models leak their real creator)

### Critical vulnerabilities:
1. **reasoning_tokens exposed in every response** — unwinnable; this is a proxy-layer artifact
2. **reasoning_details array leaks full chain-of-thought** — includes system prompt directives verbatim
3. **Model routing exposed** via `/v1/models` endpoint
4. **Streaming returns 502** — incomplete proxy implementation
5. **Static prompt_tokens=45** across all requests regardless of prompt length
